# Exemplos sintéticos de inferência

[English](README.md) | **Português**

Todos os casos de [synthetic_cases.csv](synthetic_cases.csv) foram inventados para demonstrar o software. Nenhum representa um indivíduo da base da competição. Não há rótulos verdadeiros.

[synthetic_predictions.csv](synthetic_predictions.csv) registra a saída ilustrativa do modelo congelado nesses casos inventados, com limiar 0,60. Não é um benchmark de desempenho nem orientação sobre resultados de vistos.

A terceira linha inclui intencionalmente uma categoria desconhecida, quantidade negativa de empregados e salário ausente. Siga o [guia de inferência](../docs/INFERENCE.pt-BR.md) para validar a entrada ou executar a previsão.
